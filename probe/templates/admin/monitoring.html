Application settings

Saved WebUI settings are the source of truth and apply live. Docker environment variables only seed an initial configuration; old Docker values do not override your WebUI changes. Database connection details are managed separately below.

Monitoring changes apply live. Database engine changes require a worker reload, which briefly interrupts the WebUI. Container services and port mappings still require Docker Compose.
